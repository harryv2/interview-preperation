Parking lot


- Users can visit an entry gate and ask for a ticket
- System will assign a ticket to the user and mark the slot as taken
- User can proceed to slot and park
- User can submit ticket at exit gate
- user will be shown price at exit gate
- user will pay at exit gate via Fastag, UPI, CARD
- slot will be marked as free

Relations
- parking lot will have multiple floors
- each floor will have multiple slots
- slot will be of type -> BIKE/CAR/TRUCK


Swapable logics behind inferfaces
 - slot allocation logic
 - payment methods
 - how to calculate price
